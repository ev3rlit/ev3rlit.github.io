# 최범휘

C++ 서버 개발 경험을 기반으로 Go·MongoDB를 학습하여 6개월 만에 상용 서비스를 런칭했고, 에러 핸들링·트랜잭션·로그 파이프라인을 초기 설계부터 구축하여 런칭부터 21개월 안정 라이브 운영을 달성했습니다. 첫 프로젝트에서 에러 추적 체계 없이 운영하며 겪은 어려움이 이 설계 원칙의 출발점이었습니다.

복잡한 구조보다 단순하고 명확한 설계를 지향합니다. 혼자 잘 짜는 코드보다 팀 전체가 생산적으로 일할 수 있는 구조를 먼저 고민하며, 같은 실수를 반복하지 않고 실패에서 배운 교훈을 다음 설계에 반영하는 것을 추구합니다.

게임 서버라는 도메인에서 실시간 처리, 동시성 제어, 무중단 마이그레이션 같은 도전적인 문제를 풀며 개발 자체의 즐거움을 알게 되었습니다. 앞으로는 백엔드 전반으로 영역을 넓혀 다양한 도메인에서 경험을 쌓고 성장해 나가고 싶습니다.
