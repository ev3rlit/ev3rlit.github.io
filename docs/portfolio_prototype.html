03 Problem

Go 언어의 기본 에러 처리만으로는 스택 트레이스와 Context 부재로 로그만 보고 원인을 찾기가 불가능했습니다.

03 Solution

Error as Value 패턴을 응용하여, 에러 발생 시점의 모든 문맥 정보를 수집하는 미들웨어와 래퍼를 구현했습니다.

04 Process
  • Context Middleware: UserID, Request Params, Code Line 자동 캡처
  • Onboarding: 팀원 코드 컨벤션 통일 및 가이드 작성
06 Growth

막연한 추측이 아닌 데이터 기반 디버깅이 가능해졌습니다. "추적 불가능한 에러는 없다"는 확신을 얻었습니다.
